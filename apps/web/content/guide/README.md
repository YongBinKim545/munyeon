- `slug`는 주소가 된다(한글, 띄어쓰기 대신 붙여 쓰거나 `-`). 바꾸면 옛 주소가 404가 되니 게시 뒤에는 바꾸지 않는다.
- `updated`는 기준일이다. 내용을 고치면 함께 바꾼다(사이트맵 수정일·구조화 데이터에 쓰인다).
