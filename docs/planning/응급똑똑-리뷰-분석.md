# 응급똑똑 사용자 리뷰 분석

> 수집일: 2026-10-18. 대상: 앱스토어 텍스트 리뷰 9건 전체(RSS 피드), 구글플레이 텍스트 리뷰 46건(웹에서 열람 가능한 전체). 스팸 1건을 빼면 54건이다. 표본이 작으므로 비율보다 **유형과 시기 변화**를 근거로 쓴다.

## 앱 현황

| 항목 | 앱스토어 | 구글플레이 |
|---|---|---|
| 평점 | 4.0 (평가 26개) | **2.8 (리뷰 66개)** |
| 다운로드 | 공개 안 됨 | **5만+** |
| 최신 버전 | 1.1.0 (2026-10-08 전후) | 2026-10-08 업데이트 |
| 개발사 답글 | 없음 | **0건** |

- 출시 2025-07-30(1.0.0). 운영 주체는 보건복지부, 안드로이드 패키지명으로 보아 개발은 빔웍스(kr.co.beamworks)로 추정.
- 구조: 증상 입력(AI 자연어 검색 또는 신체 부위 버튼) → 맞춤 질문 → 중증도 분류 → 추천 병의원·응급실 리스트. 별도로 '주변 의료시설' 탭에서 위치 기준 병의원·약국·달빛어린이병원·AED를 볼 수 있다.
- 스크린샷 기준 추천 병원 리스트에는 진료 중 표시, 진료시간, 거리만 있고 **전화 버튼은 없다**. 전화하려면 상세 화면으로 한 단계 더 들어가야 하는 것으로 보인다(상세 화면의 전화 기능은 직접 확인하지 못함).
- 업데이트 이력: 2025-10-03~06 사이 안정성·로딩 속도 수정 3회(추석 장애 대응) → 2026-02 안정성 → 2026-07 아이안심톡 연결 버튼, 달빛 '취약지 야간·휴일 진료' 배지 → 2026-09 접근성 인증 → 2026-10 폴더블 대응, 달빛 진료시간 구분 표시, 치과 검색 확대. 꾸준히 고도화 중이지만 **데이터 정확도를 다룬 업데이트는 없다**.

### 시기별 변화

- **2025년 추석: 인프라 문제.** 정부 홍보로 설치가 한꺼번에 몰렸는데 서버가 버티지 못했다. 이후 수정됐다.
- **2026년 추석: 데이터 문제.** 장애 리뷰는 사라지고 "표시는 진료 중인데 실제로는 닫혀 있다"는 리뷰가 주류가 됐다. 한 리뷰는 앱이 불일치할 수 있으니 전화해 보라고 안내한다면서 그러면 네이버 지도와 다를 게 없다고 했다.
- 즉 공식 앱의 남은 약점은 **화면이 아니라 데이터 신뢰도**다. 이는 API 검증에서 확인한 일요일·공휴일 진료시간 등록률(병의원 9%, 약국 26%)과 같은 원인이다([API 검증 결과](API-검증결과.md)).

## 지금문연 계획과의 대응

| 응급똑똑 불만 | 지금문연 대응 | 세부계획 현재 위치 |
|---|---|---|
| '진료 중'인데 휴진 | 통화 후 1탭 확인 → "N분 전 통화로 확인됨" 배지, 휴진 제보 시 강등 | **MVP** (2026-10-18 v1.1에서 이동) |
| 오류 신고 버튼 요청 | 위와 같은 루프 + 카드별 휴진 제보 버튼 | **MVP** |
| 증상 입력 부담 | 증상 판단 없이 첫 화면이 '지금 연 곳 + 전화' | MVP |
| 리스트에서 전화까지 단계가 많음 | 카드에서 바로 `tel:` | MVP |
| 명절 피크 접속 장애 | 모바일 웹 + 서버 캐시, 설치 없이 링크로 진입 | MVP 아키텍처 |
| 시니어 글씨 | 큰 글씨 모드 | 페르소나 P3 |
| 119 버튼 오터치 | 119는 확인 단계를 둔 별도 영역에 배치 | MVP |
| 한의원 미포함 | 전체 포함, 기본 필터에서만 숨김 | MVP(기본 필터 켬) |
| 입원 가능 병원 표시 | 응급실 가용병상 API 연계 검토 | v2 |
| 개발사 무응답 | 리뷰·제보 응대 자체를 운영 원칙으로 | 미반영 |
