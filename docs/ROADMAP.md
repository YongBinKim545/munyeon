## 법률·행정 확인

- **위치정보법:** 사용자 위치로 주변 기관을 찾는 기능이 위치기반서비스사업 신고 대상인지 확인한다. 좌표를 서버에 저장하지 않고 격자 단위로 반올림해 조회하는 설계를 함께 검토한다.
- **의료광고법:** "병원 정보 제공 서비스"의 순위 표시·수익화 범위.
- **개인정보처리방침·이용약관:** 확인 응답·제보 데이터의 처리 범위.
- **공공데이터 이용:** 출처 표시, 운영계정 트래픽 증량을 위한 활용사례 등록. 공휴일 판정용 한국천문연구원 특일 정보 API 활용신청(완료 10-19).
