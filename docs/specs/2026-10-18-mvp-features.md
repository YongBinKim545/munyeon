## 1. 목적과 성공 기준

- **목적:** 야간·휴일·명절에 지금 문 연 병원·약국을 3초 안에 찾아 원탭으로 전화 확인한다.
- **1차 타깃:** 아이가 아픈 맞벌이 부모(P1). 1인 가구(P2), 고령 부모를 대신 찾는 자녀(P3).
- **성공 기준(세부계획 §9):** 북극성 지표는 주간 전화 연결 수. 진입→전화 전환율 25% 이상, 진입→전화 중앙값 15초 이하. 확인 응답률은 수집만 하므로 목표 대신 실측치로 본다.
- **정직한 표시 원칙:** '등록 기준'과 '정보 없음'을 구분해서 보여주고, 정보 없음을 휴무로 표시하지 않는다. 모든 기관 정보 옆에 "방문 전 전화로 확인"을 둔다.

## 2. 기능 목록과 단계

| 기능 | 단계 | 요약 |
|---|---|---|
| 기관 상세 페이지 | 1a | 진료시간표, 원탭 전화, 길찾기, 지금 상태(브라우저 계산). 약 10.4만 페이지 |
| 지역 화면 | 1a | 시군구 × 약국/병원, 메인과 같은 목록 + [언제 ▾](D69) |
| 지역 검색(옛 위치 검색, D52) | 1a | 메인 지역 드롭다운 안의 모달. 동네 이름을 브라우저 안에서 찾고, 고르면 메인 목록의 중심이 바뀐다(D33) |
| 상호 검색 | 1a | 별도 페이지 `/search`. 병원·약국 이름을 우리 DB 색인으로 찾고, 보고 있는 지역에서 가까운 순(D33) |
| 메인(현재 위치 목록) | 1a | 메인 전용 헤더(지역·유형·상태) + 거리순 목록 + [전체 보기] + 서버 HTML 시도 목록(D31·D32·D35) |
| 원탭 전화 | 1a | 카드·상세에서 바로 `tel:` |
| 길찾기 딥링크 | 1a | 네이버지도·카카오맵·티맵 앱(없으면 웹). 지도 뷰는 없다 |
| 진료과·소아 배지 | 1a | 카드마다 이름 기준 주 진료과 배지 1개 + '소아 전문' 배지. 상단 필터 줄은 없다 |
| 통화 후 질문 | 1b | 1탭 응답 + 선택형 제보. **수집만 하고 실시간 표시는 보류** |
| 연휴 특집 페이지 | 2027-01 초 | 설 연휴 시도·시군구별 |

**MVP에서 하지 않는 것:** 지도 뷰, 실시간 '○분 전 확인' 배지(소프트 런칭 실측 후 결정), 자유 댓글·별점(v2 이후 계정 기능과 함께), 119 전화 버튼, 즐겨찾기·공유·큰 글씨(v1.1), 예약·비대면진료·약 재고·커뮤니티(기존 Won't).

## 3. 공통 규칙

### 3.1 영업 상태 판정

- 우선순위: 공표 진료시간 → 공휴일(요일코드 8) → 명절 당직(API 반영 여부 12-25 재검증 후) → 이용자 확인(표시 보류 중이라 MVP에서는 판정에 쓰지 않음).
- 자정 넘김 두 표기(`0900-2500`, `2000-0300`)를 모두 처리한다. 전날 시작한 구간은 전날의 요일코드로 판정한다.
- 공휴일인데 코드 8이 없으면 '정보 없음'이다. 평일 시간으로 대체해 '영업 중'이라고 하지 않는다.
- 현재 상태는 서버 HTML에 넣지 않고 브라우저에서 계산한다. 시각은 항상 한국 시간 기준이다.

### 3.2 상태 문구

| 상태 | 문구 예 |
|---|---|
| 영업 중 | "영업 중 · 오후 6시 마감 (등록 기준)", 1시간 이내면 "곧 마감 · 40분 남음" |
| 영업 전 | "영업 전 · 오전 9시 시작" |
| 영업 종료 | "영업 종료 · 내일 오전 9시 시작"(내일 정보가 있을 때) |
| 정보 없음 | "오늘 정보 없음 — 전화로 확인" |
| 공휴일 | 위 문구 앞에 "오늘은 공휴일 · 공휴일 진료시간 기준" |

상태 문구에는 "(등록 기준)"을 붙이지 않는다("영업 중 · 오후 6시 마감", "곧 마감 · 40분 남음", "24시간 영업"). 메인 목록은 맨 위에 한 번 안내하고(D42, 4.4), 기관 상세는 상태 아래 "등록된 정보가 실제와 다를 수 있어요. 방문 전 꼭 전화로 확인하세요."가 대신한다(D49).

### 3.3 기관 종류 구분

- 약국: 약국 API 전체.
- 병원 '일반 진료': 종별이 의원·병원·종합병원·상급종합병원·보건소 계열이고 한의원·한방병원·치과의원·치과병원이 아닌 곳.
- 한의원·치과: 데이터는 모두 수집하고 상세·지역 페이지도 만든다. 메인 병원 목록에서는 접지 않고 **각 구간의 맨 아래**에 둔다(D32). 지역 랜딩에서는 목록 끝 "한의원·치과도 보기 (n곳)" 한 줄로 접는다(4.2).
- 요양병원·정신병원·조산원: 한의원·치과와 같이 취급한다(메인은 각 구간 맨 아래, 지역 랜딩은 접힌 줄).
- 주 진료과 배지 규칙은 [구조 설계·UI/UX 계획](2026-10-18-architecture-ux.md) 4.3.

### 3.4 응급 안내

- 119 전화 버튼은 두지 않는다(오터치 원인, 119는 모두 안다).
- 기관 상세와 결과 0곳 화면에 링크 없는 안내 문구 한 줄: "의식이 흐리거나 숨쉬기 어려우면 바로 119에 연락하세요."

## 4. Phase 1a 상세

### 4.1 기관 상세 페이지 (`/pharmacy/{기관ID}`, `/hospital/{기관ID}`)

**화면 순서(모바일 한 열)**

1. 이름 · 종별 · 주소
2. 지금 상태 줄(3.2, 브라우저 계산)
3. **[전화하기]** 큰 버튼(주 동작) + [길찾기] 버튼(네이버·카카오·티맵 선택 시트)
4. "등록된 정보가 실제와 다를 수 있어요. 방문 전 꼭 전화로 확인하세요." + "데이터 기준: 2026-11-20 14:07"(마지막 성공 동기화)
5. 요일별 진료시간표: 월~일 + 공휴일. 오늘 행 강조. 빈 칸은 '정보 없음'. 자정 넘김은 "20:00~익일 03:00", 24시간은 "24시간"
6. 응급 안내 문구(3.4)
7. 출처: 국립중앙의료원 · 공공데이터포털(공공누리 표시)

**예외**

| 상황 | 동작 |
|---|---|
| 진료시간 전부 비어 있음 | 페이지는 보여주고 `noindex`. 진료시간표 자리에 "등록된 진료시간이 없어요 — 전화로 확인" |
| 전화번호 없음·형식 오류 | 전화 버튼 대신 "전화번호 정보 없음" |
| 좌표 없음 | 길찾기는 주소 검색 링크로 |
| 동기화에서 사라진 기관 | 404 대신 "현재 운영 정보가 없습니다. … 위 지역 목록에서 다른 ○○을 찾아보세요", `noindex`, 사이트맵 제외 |
| 없는 기관 ID | 404 + [메인으로] [상호 검색] |

**검색 노출**

- 제목: 약국 "○○약국 영업시간 · 일요일·공휴일 | 찾아줘 메디", 병원 "○○의원 진료시간 · 일요일·공휴일 | 찾아줘 메디"
- 설명: 주소 + 일요일·공휴일 시간 요약(예: "일요일 10:00~14:00, 공휴일 정보 없음")
- 구조화 데이터: schema.org `Pharmacy` / `MedicalClinic`, `openingHoursSpecification`(월~일, 정보 있는 요일만), `telephone`, `address`, `geo`
- 캐시: 하루 단위 재생성(ISR). 진료시간이 바뀌면 사이트맵 `lastmod`가 바뀐다.
- 처음 열리는 기관은 서버가 그 자리에서 페이지를 만들어 몇 초 걸릴 수 있다. 그동안 제목·줄 모양의 틀과 "정보를 불러오고 있어요…"를 바로 보여준다(2026-10-21, `loading.tsx`). 틀에는 영업 상태 문구를 넣지 않는다.
- (D45·D51) 메인 목록·지역 페이지 목록·이름 검색에서 누르면, 그 화면이 가진 정보로 상세를 **누르는 즉시** 덮어 그린다(서버 응답을 기다리지 않음): 경로, 이름, 배지, 동네·주소, 지금 상태, [전화하기] [길찾기], 진료시간표. 아래에 "나머지 정보를 불러오고 있어요…". 서버 상세가 화면에 붙으면 덮개를 걷는다(주소·데이터 기준 시각 추가). 서버가 끝내 실패하면 덮개를 둔 채 "일부 정보를 불러오지 못했어요 [다시 시도]" 한 줄. 뒤로 가기는 덮개를 닫고 목록으로 돌아간다. 새 탭으로 열면 서버 페이지를 그대로 기다린다.
- (D51) 근처 기관 구역은 두지 않는다(처음 여는 속도). 다른 곳은 경로의 지역 페이지·메인에서 찾는다.
- (D50·D51) 서버 DB 조회는 3초 제한·새 연결로 1회 재시도. 그래도 실패하면 "정보를 불러오지 못했어요" + [다시 시도] [메인으로](캐시되지 않음).

### 4.2 지역 화면 (`/{시도}/{시군구}` 약국, `/{시도}/{시군구}/병원`, D69)

- 메인(4.4)과 같은 목록에 지역만 시군구로 고정한다. 상황별 페이지(일요일·공휴일·야간)와 `/…/약국/전체`는 없애고 301로 이 화면에 모은다.
- 제목: "서울 마포구 약국 — 지금 문 연 곳·일요일·공휴일 영업시간"(P0-2 시도 약칭), H1 "서울 마포구 약국". 그 아래 요약 한 문단(P0-3): "서울 마포구 약국은 등록 기준 211곳이에요. 평일 가장 늦게까지 하는 곳은 ○○약국(밤 12시), 가장 일찍 여는 곳은 ○○약국(오전 8시)이에요. 일요일에 여는 곳은 60곳, 공휴일 시간을 등록한 곳은 31%예요. 방문 전 꼭 전화로 확인하세요. (국립중앙의료원 자료, 10월 25일 기준)". 가장 늦게/일찍은 평일(월~금) 등록 시간 기준, 같으면 가나다순, 추천 표현 없음. 현재 상태는 넣지 않는다.
- 둘째 줄 [유형 ▾] [언제 ▾]. 유형을 바꾸면 약국 화면·병원 화면 주소로 이동하고, 소아과는 병원 화면 안에서 거른다(`#소아과`).
- 목록 규칙·카드·[전체 보기]는 메인과 같다. 거리는 그 시군구 기관 좌표의 가운데값 기준이고 "거리는 마포구 중심 기준이에요 · [내 동네 기준으로 보기]" 한 줄로 밝힌다. 위치 권한은 묻지 않는다(D56).
- [내 동네 기준으로 보기]: 위치를 이미 허용했으면 메인(현재 위치), 아니면 이 시군구의 동만 보이는 지역 검색 → 고른 동으로 메인(마지막 지역으로 기억).
- 날짜를 고르면 주소에 `?날짜=`가 붙어 그대로 공유된다(서버는 읽지 않는다, D23).
- 서버 HTML: 목록 자리에는 "목록을 준비하고 있어요…"만 두고(현재 상태 없음), 아래 접힌 "○○ 약국 전체 n곳 (이름순)"에 이름·동·진료시간 요약(평일·토·일·공휴일)과 상세 링크를 모두 넣는다(검색 로봇·글자 화면용).
- 맨 아래 같은 시도의 다른 지역 칩(같은 유형 화면으로).

### 4.3 위치 검색과 상호 검색 (D33·D43·D70)

- 헤더 [검색]을 누르면 검색 화면(휴대폰 화면 전체, PC 가운데 창)이 열리고 위에 탭 **[지역] [기관 이름]**이 있다. 처음은 [지역], 이후 마지막에 쓴 탭. 주소에 `?q=`가 있으면(상세에서 뒤로 돌아옴) [기관 이름].
- [지역]에서 동을 고르면 메인이 그 동으로 열린다(현재 위치보다 먼저, 마지막 지역으로 기억).

**공통 검색 틀 (D43)**

- 윗줄: [입력칸] [검색](테두리 버튼). 검색은 [검색]이나 엔터로만 실행하고, 실행하면 휴대폰 키보드를 닫는다.
- 가운데: 결과 목록. 찾는 동안 로더("찾는 중…"), 결과가 없으면 "찾는 ○○이 없어요", 두 글자 미만이면 "두 글자 이상 입력하세요".
- 맨 아래: 전체 너비 [닫기](길찾기 창과 같은 모양). 휴대폰에서는 화면 아래에 붙어 결과가 길어도 바로 누를 수 있다.
- (D45) 휴대폰에서 입력칸에 포커스가 가면 키보드가 [닫기]를 가리므로, [닫기]를 검색창 바로 아래로 옮긴다. 키보드가 실제로 내려가면(화면 높이가 돌아오면) 맨 아래로 돌린다. 포커스가 빠지는 순간에는 옮기지 않는다(결과를 누르는 중에 배치가 움직이지 않게).
- 휴대폰(~767px)은 화면 전체, 태블릿·PC는 가운데 창.

**지역 검색 (모달, 메인에서만. D52 전 이름은 위치 검색)**

- [위치 찾기] › [지역 검색]으로 연다. 검색창이 비어 있으면 그 아래에 최근 지역 3개(최근 고른 순)를 보여준다(D38). 휴대폰(~767px)은 화면 전체를 덮고, 태블릿·PC는 가운데 모달이다.
- 닫기: 닫기 버튼, Esc, 휴대폰 뒤로 가기, (태블릿·PC) 모달 바깥 누르기. 뒤로 가기는 모달만 닫고 페이지를 떠나지 않는다. 모달이 열려 있는 동안 Tab은 모달 안에서만 돈다.
- 입력: 읍면동 또는 시군구 이름(예: "영통동", "망원", "강남구"). 두 글자부터, [검색]을 누르면 브라우저 안에서 찾는다. 동네 목록 JSON은 모달을 처음 열 때 받고, 받는 중에 검색하면 로더를 보여준다.
- 동네 목록: 기관 주소 끝 괄호의 동 이름(예: "(역삼동)")과 시군구에서 만든다. 동네 중심 좌표는 그 동네 기관 좌표의 중앙값이고, 동네 목록 JSON에 함께 담는다(고른 동네를 메인 목록 중심으로 쓴다). 좌표가 없는 동네는 결과에 내지 않는다. 외부 주소 API를 쓰지 않는다.
- 결과가 없으면 "찾는 동네가 없어요".
- 같은 동 이름이 여러 지역에 있으면 "망원동 · 서울 마포구"처럼 시군구를 붙여 고르게 한다.
- 고르면 모달이 닫히고 메인 목록의 중심이 그 동네 중심 좌표로 바뀐다. 고른 지역은 최근 지역 맨 앞에 들어간다.

**상호 검색 (페이지 `/search`)**

- 헤더의 [검색]으로 간다(메인은 2줄 오른쪽, 다른 페이지는 로고 줄 오른쪽). `noindex`, 사이트맵 제외.
- 화면은 위치 검색 모달과 같은 모양(공통 검색 틀)이다. [닫기]는 직전 화면으로 돌아가고, 주소로 바로 들어와 직전 화면이 없으면 메인으로 간다.
- 병원·약국 이름만 찾는다. 2글자부터, [검색]이나 엔터를 누르면 1회 조회(조회 중 로더), 최대 20건. 검색어는 주소(`?q=`)에 남아, 뒤로 가기로 돌아오면 다시 조회해 결과를 보여준다.
- 정렬: 메인에서 보던 지역에서 가까운 순(D37). 서버에는 좌표 대신 약 5km 격자 번호만 보내고, 서버는 그 칸 중심에서 가까운 20건을 돌려준다. 브라우저가 메인에서 보던 중심 좌표(이 브라우저에만 저장)로 거리를 계산해 다시 정렬한다. 메인을 본 적이 없으면 이름 앞부분 일치 → 짧은 이름순.
- 행: 이름 · 진료과 배지 · 시군구 · 거리(보던 중심이 있을 때), 전화 아이콘(바로 전화). 행을 누르면 상세. 결과가 없으면 "찾는 병원·약국이 없어요".
- 검색어는 서버에 저장하지 않는다. 초성 검색·오타 보정은 v1.1 판단.

### 4.4 메인 `/` (1a, D31·D32·D34·D41)

**헤더 (메인 전용)**

- 로고 줄: 찾아줘 메디 로고 이미지(누르면 메인) + 아래 작은 글씨 "지금 문 연 병원·약국을 찾아드려요", 오른쪽 위 [검색](이름 검색, 4.3, D69). [개선의견]은 모든 페이지 맨 아래 푸터 바로 위(4.5). 다크 모드에서는 흰 글자 버전으로 바뀐다(D44, 브랜드 원본은 `D:/planning/brand/findmedi/`, 파비콘·아이콘·공유 이미지 위치는 그 폴더 README의 표).
- 1줄(D38): 📍 지역 이름(글자, 예: '중구 명동') + **[위치 찾기 ▾]**. 표시는 시군구 + 동이다. 같은 이름의 시군구가 여러 시도에 있으면 '부산 중구'처럼 시도를 붙인다.
  - 현재 위치일 때 지역 이름은 가장 가까운 기관의 시군구·동으로 붙인다(외부 주소 API 없음).
  - [위치 찾기] 메뉴: [현재 위치] / [지역별 보기](`/regions` 지역으로 찾기 페이지로 이동, D52). 지역 검색은 헤더 [검색]의 [지역] 탭(4.3, D70). 최근 지역 3개는 그 탭 안에 있다.
- 2줄(D41·D69): [약국 ▾] [언제 ▾]. '유형'·'언제' 글자는 화면에 보이지 않고 화면 낭독기용 이름으로만 둔다.
  - 언제: **지금 문 연**(기본) / 고른 날짜 / 날짜(휴대폰 기본 달력, 오늘부터 90일). 고른 날짜는 이 방문 동안만 기억한다. 날짜 목록은 '지금'과 같은 규칙이다: 그날 여는 것으로 등록된 곳(카드 '10/25(일) 09:00~18:00') → 공휴일이면 코드 8이 없고 평소 그 요일 시간이 있는 곳('전화 확인 필요 · 평소 금요일 09:00~18:00') → 나머지 정보 없음은 [전체 보기] 안. 응급 안내 문구는 '지금 문 연'에서만.
  - 유형: 약국 / 병원 / 소아과. 처음은 약국, 이후 마지막 선택을 기억한다.
  - 병원: 모든 병·의원(소아과 포함). 소아과: 이름에 소아청소년과·소아과 또는 '소아·아동·어린이·키즈'가 들어간 일반 병·의원(2026-10-21 dev DB 2,204곳). 다른 진료과는 고르지 않고 이름 검색으로 찾는다.
  - 상태 선택(영업 중/전체)은 없다. 늘 영업 중 목록으로 시작하고, 나머지는 목록 끝 [전체 보기]로 펼친다.
- 스크롤(D52): 로고 줄은 늘 위에 고정. 지역·유형 두 줄은 로고 줄 아래에 붙어 있다가, 아래로 스크롤하면 숨고(로고 줄 뒤로) 위로 조금이라도(12px 넘게) 올리면 다시 나온다. 맨 위 80px 안에서는 늘 보이고, [위치 찾기] 메뉴가 열려 있으면 숨지 않는다. 줄 높이는 줄이지 않는다. [↑ 맨 위로] 버튼은 없앴다.
- 다른 페이지(기관 상세·지역·소개 등)의 헤더도 로고 줄(소개 문구, [검색])만 있다(D69).

**위치 (D34)**

- (D38) 들어올 때 위치 권한을 자동으로 묻지 않는다. 이 브라우저가 이미 위치를 허용했으면(권한 상태 조회, 창 없음) 현재 위치로 시작하고, 아니면 **마지막으로 보던 지역**(D45: 현재 위치로 찾은 곳 포함, 이름·좌표를 이 브라우저에만 저장), 없으면 최근 지역, 없으면 서울 중구 명동(고정 좌표)으로 시작한다. 경고 문구는 없다.
- (D73) 같은 탭 안에서 메인에 다시 들어오면(상세에서 뒤로가기, 로고로 홈) 위의 시작 규칙 대신 **이 탭에서 보던 지역**으로 바로 연다(검색·지역별 보기로 고른 동, 현재 위치 모두). 위치를 다시 잡지 않는다. 지역 화면의 [내 동네 기준으로 보기]는 위치를 허용한 경우 현재 위치로 연다.
- 위치를 찾는 동안 지역 자리에 "위치 찾는 중…", 목록 자리에 "가까운 곳을 찾고 있어요…".
- [위치 찾기] › [현재 위치]를 누르면 위치를 요청한다. 아직 정하지 않았으면 브라우저 권한 창이 뜨고, 허용하면 현재 위치 목록이 된다.
- 거부된 상태면 **위치 권한 안내 모달**: 제목 "위치 권한이 꺼져 있어요", "현재 위치로 찾으려면 브라우저에서 위치 권한을 허용해 주세요.", 기기별 켜는 방법(아이폰 사파리 / 안드로이드 크롬 / PC 크롬·엣지 / 카카오톡·네이버 앱이면 "크롬이나 사파리로 열어 주세요"), "허용한 뒤 [다시 시도]를 눌러 주세요." + [다시 시도] [지역 검색으로 찾기] [닫기]. 기기를 알 수 있으면 그 기기 안내만, 모르면 전부.
- 권한은 있는데 위치를 못 잡으면(위치 서비스 꺼짐·8초 초과) 같은 모달에 제목 "위치를 찾지 못했어요", "휴대폰의 위치 서비스가 켜져 있는지 확인해 주세요."
- 위치를 기다리는 사이 사용자가 고른 지역은 덮지 않는다.
- 지역·유형을 바꾸면 새 목록을 맨 위에서 보여준다. [전체 보기]로 펼쳤던 목록도 다시 영업 중 목록이 된다.
- 유형·최근 지역은 브라우저에만 저장한다. 좌표는 서버로 보내지 않는다(서버에는 약 5km 격자 번호만, D21).
- 휴대폰 브라우저는 `https://` 주소에서만 위치를 허용한다.

**목록 (D32)**

- 데이터: 중심 주변의 격자 목록 JSON(CDN 1시간 캐시). 거리·영업 판정·정렬은 브라우저가 한다. 반경 1km를 먼저 받아 그리고 3km는 이어서 받는다. 늦게 온 기관도 순서 규칙대로 제자리에 들어가고, 보고 있는 카드는 움직이지 않는다(D36).
- 범위: 중심에서 3km로 시작하고, 보여줄 곳(아래 ①~③)이 5곳 미만이면 10km, 25km로 넓힌다. 소아과는 소아과만 센다. 동 경계 밖이어도 가까우면 포함한다.
- 구역 제목 없이 한 줄로, 위에서부터:
  1. **지금 영업 중(등록 기준):** 상태 문구는 3.2. 카드에는 "(등록 기준)" 없이 "영업 중 · 오후 6시 마감", "곧 마감 · 40분 남음"(D42).
  2. **곧 영업:** 지금 영업 중이 아니고 2시간 안에 연다(자정을 넘겨도, 내일이 공휴일이면 코드 8 기준). 오늘 칸이 비어 있어도(정보 없음) 내일 2시간 안에 열면 여기에 넣는다(D37). 배지 '곧 영업 · 40분 뒤 오후 8시 40분', '곧 영업 · 1시간 30분 뒤 오후 9시 30분'.
  3. **(공휴일만) 전화 확인 필요:** 오늘 공휴일 시간(코드 8)은 없지만 오늘 요일의 평소 시간으로는 지금 영업 중인 곳. 배지 '전화 확인 필요' + 문구 '평소 금요일엔 이 시간 영업'. 평소 그 요일 시간도 없는 기관은 넣지 않는다.
- 각 구간 안은 거리순이고, 병원이면 한의원·치과(요양·정신·조산 포함)는 그 구간의 맨 아래(그 안에서 거리순)에 둔다.
- 목록 끝 **[전체 보기]:** 누르면 같은 범위의 나머지(문 닫은 곳, 정보 없는 곳)가 거리순으로 아래에 붙는다(한의원·치과는 맨 아래). 구분 문구는 없고, 위쪽 목록과 스크롤 위치는 그대로다.
- ①~③이 하나도 없으면: "등록 기준으로 지금 문 연 곳이 없어요"(소아과는 "지금 문 연 소아과가 없어요") + 응급 안내 문구(3.4) + [전체 보기].
- 소아과에서 25km까지 넓혀도 ①~③이 5곳 미만이면, 목록 끝에 "가까운 곳에 지금 문 연 소아과가 적어요" + [가까운 병원 보기](유형을 병원으로 바꾼다).
- 데이터를 받지 못하면(D37): 하나도 못 받았을 때 "목록을 불러오지 못했어요" + [다시 시도](위 '없어요' 문구 대신), 일부만 못 받았을 때 받은 목록 위에 "일부를 불러오지 못했어요" + [다시 시도]. 실패하면 반경을 넓히지 않는다.
- (D45) 카드는 처음 10곳만 그린다. 그 아래 [n곳 더 보기 (남은 m곳)]를 누를 때만 10곳씩 늘린다(자동으로 이어 붙이지 않는다). 누르면 새로 나온 첫 카드로 포커스를 옮긴다. [전체 보기]는 영업 중인 곳을 다 펼친 뒤에 나온다. 더 받는 중에는 "더 찾는 중…".
- 공휴일 판정에 쓰는 공휴일 목록은 메인 HTML에 담겨 온다(D37).
- 공휴일이면 목록 위에 "오늘은 공휴일 · 공휴일 진료시간 기준" 띠.
- 목록 맨 위(카드가 하나 이상일 때)에 한 번: "영업시간은 등록 기준이에요 · 방문 전 전화로 확인하세요"(D42).
- 카드: 이름 · 거리 / 진료과 배지 · 소아 전문 배지 / 상태 문구 또는 배지 / [전화하기](진한 색) [길찾기](테두리) 나란히. 이름을 누르면 상세. PC는 전화번호를 한 줄에 두고 그 아래 [번호 복사] [길찾기] 나란히(D29, 긴 번호에서 버튼이 넘치지 않게). 같은 카드 모양을 지역 페이지에도 쓴다.
- 목록 아래: "등록된 정보가 실제와 다를 수 있어요. 방문 전 꼭 전화로 확인하세요." + "데이터 기준: 날짜·시각".

**서버 HTML (검색 로봇·위치를 못 쓰는 사람용)**

- 헤더 틀, 안내 문구, 공휴일 목록은 서버에서 그린다(1시간 캐시). 지역으로 찾기(시도 목록)는 `/regions` 페이지로 옮겼고(D52), 모든 페이지 푸터에 "지역으로 찾기" 링크가 있다. 제목(h1) "지금 문 연 병원·약국"은 화면에서는 숨기고 검색 로봇·화면 낭독기용으로 둔다.
- 목록과 지역 이름은 브라우저에서만 그린다. 영업 상태는 HTML에 들어가지 않는다.

### 4.5 개선의견과 수정요청 (D49)

**공통 창**

- 휴대폰은 화면 전체, 태블릿·PC는 가운데 창. 제목 줄 오른쪽 [X], 맨 아래 전체 너비 [보내기](테두리 버튼). 뒤로 가기·Esc·[X]로 닫힌다.
- 휴대폰 키보드가 올라오면 창 높이를 보이는 화면에 맞춰 [보내기]가 키보드 바로 위에 남는다.
- 입력란 아래 "이름·전화번호 같은 개인정보는 적지 마세요." 500자까지(글자 수 표시).
- 쓰던 내용은 창을 닫았다 다시 열어도 남는다(이 탭의 메모리, 저장하지 않음).
- 보내면 "고마워요 / 보내주신 내용은 확인해서 서비스를 고치는 데 쓸게요." + [닫기]. 실패하면 "보내지 못했어요. 잠시 뒤 다시 시도해 주세요."
- 같은 브라우저에서 1분에 한 번만 보낸다(그 안에 다시 누르면 "잠시 뒤 다시 보내 주세요").

**[개선의견] (모든 페이지 헤더 오른쪽 위)**

- 제목 "개선의견", 입력란 하나("어떤 점이 불편했나요?"). 빈 내용은 보낼 수 없다("내용을 적어 주세요").

**[수정요청] (기관 상세에만)**

- 상태 아래 안내 문구 옆에 [정보 수정 요청]. 제목 "정보 수정 요청" + 기관 이름.
- 칩(여러 개): 전화번호 / 영업시간(병원은 진료시간) / 상호 / 주소 / 폐업 / 기타. 하나 이상 골라야 보낸다("틀린 항목을 골라 주세요").
- 입력란은 선택("맞는 정보를 알면 적어 주세요"). 기타를 골랐으면 내용이 있어야 보낸다("기타 내용을 적어 주세요").

**저장**

- `feedback` 표: 종류(opinion·correction), 내용, 칩, 기관 종류·번호(수정요청), 페이지 경로, 분 단위 시각. IP·기기 정보·좌표는 저장하지 않는다.
- 서버는 함수 인스턴스당 10초에 20건까지, 10분 안에 같은 내용이 다시 오면 받지 않는다(성공처럼 응답).
- 확인은 Supabase 표 편집기에서 한다(관리 화면은 나중에).

## 5. Phase 1b 규칙

### 5.1 지금 영업 중 리스트

1a 메인(4.4)으로 옮겼다(D31·D35). `/주변` 화면은 만들지 않는다.

### 5.2 진료과·소아 배지

- 별도 소아 탭은 두지 않는다. 소아 진료는 배지로 찾는다(D26). 이름 기준 배지는 1a, 달빛어린이병원·제보 기준은 1b.
- 주 진료과 배지: 이름 기준 1개(구조 설계 4.3). 소아청소년과 의원은 [소아청소년과] 배지가 붙는다.
- '소아 전문' 배지: 달빛어린이병원, 또는 이름에 소아·아동·어린이·키즈, 또는 최근 180일 '소아 진료 가능' 제보 2건 이상.
- 배지는 강조만 하고 정렬을 바꾸지 않는다.
- 데이터: 달빛어린이병원 목록(같은 국립중앙의료원 API)을 하루 1번 받는다. 심평원 진료과목 등 외부 데이터 보강은 MVP에서 하지 않는다(D28).

### 5.3 통화 후 질문

- 조건: [전화] 탭 후 페이지가 가려졌다가 다시 보일 때, 자리를 비운 시간이 10초 이상이면 하단 시트를 띄운다.
- 질문: "통화해 보니 어땠나요?" [진료 중] [휴진] [안 받음]. 선택 칩: 소아 진료 가능 / 공휴일에도 열었어요 / 전화번호가 달라요. 닫기 버튼이 크고, 무시해도 된다.
- 응답 후: "고맙습니다. 알려주신 내용은 정보를 바로잡는 데 쓰여요."
- 저장: 기관 ID, 응답, 칩, 분 단위 시각, 자리 비운 시간(10초 구간). 기기 식별자·IP·좌표는 저장하지 않는다.
- 중복: 같은 기관은 브라우저에서 6시간에 1번만 응답받는다.
- 활용: 소아 전문 배지(5.2), '전화번호가 달라요' 3건 이상이면 운영자 확인 목록(공공데이터포털 오류 신고로 전달), 기관별 응답 기록 축적.
- **실시간 표시 여부:** 12-25~01-01 소프트 런칭에서 응답률·지역 밀도·응답 일관성을 재고, 2027-01 중순에 설 연휴 표시 여부를 결정한다.

## 7. 개인정보·법적 고려

- 위치 좌표는 서버로 보내지 않는다(격자 번호만 요청). 위치기반서비스사업 신고 필요성을 줄이는 설계이며, 최종 판단은 법률 확인 항목으로 남긴다.
- 통화 후 응답과 제보는 개인 식별 정보 없이 저장한다.
- 자유 텍스트를 받지 않으므로 게시물 임시조치·명예훼손 대응 부담이 없다.
- 병원 노출 순서는 거리·이름순이며 금전이 개입하지 않는다.
