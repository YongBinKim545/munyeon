# UTM 규칙표 (P0-11, D60·D72)

블로그·카페·보도자료·광고에 사이트 링크를 걸 때 아래 꼬리표를 붙인다. GA4가 채널을 자동으로 나누고, 우리 이벤트 기록(전화 탭 등)에는 아래 '분류' 값 하나만 남는다.

## 규칙

- 소문자·영문·밑줄만 쓴다. 한글·공백은 쓰지 않는다.
- `utm_source`(어디서), `utm_medium`(어떤 종류), `utm_campaign`(무슨 행사) 세 개를 모두 붙인다.
- 캠페인 이름: `seollal2027`(설 연휴), `softlaunch2026`(소프트 런칭), `chuseok2027`처럼 `행사+연도`.
- 지역 페이지 링크는 인코딩된 주소를 그대로 쓴다(P1-12).

| 채널 | utm_source | utm_medium | 우리 기록 분류 |
|---|---|---|---|
| 네이버 블로그 | `naver_blog` | `blog` | 커뮤니티 |
| 티스토리 등 다른 블로그 | `tistory` 등 | `blog` | 커뮤니티 |
| 네이버 카페·맘카페 | `naver_cafe` | `cafe` | 커뮤니티 |
| 커뮤니티 게시판(더쿠·클리앙 등) | 사이트 이름(`theqoo`) | `community` | 커뮤니티 |
| 인스타그램·스레드·밴드 | `instagram` 등 | `social` | 커뮤니티 |
| 보도자료·기사 | 매체 이름(`yna`) | `press` | 기타 |
| 검색·SNS 광고 | `naver_ad`, `google_ads`, `meta_ads` | `cpc` | 광고 |

예: `https://findmedi.co.kr/서울특별시/마포구?utm_source=naver_blog&utm_medium=blog&utm_campaign=seollal2027`

## 꼬리표 없이 들어온 방문의 분류

처음 들어온 페이지에서 브라우저가 한 번 정하고, 그 탭을 닫을 때까지 기억한다.

1. `?ref=share`(공유 버튼으로 퍼진 링크, P1-2) → **공유**
2. UTM이 있으면 위 표(`cpc`·`ad`·`paid` → 광고, `blog`·`cafe`·`community`·`social` → 커뮤니티, 그 밖 → 기타)
3. 다른 사이트에서 왔으면 출처 도메인으로: 구글·네이버 검색·다음 검색·빙·줌·덕덕고 → **검색**, 네이버 블로그·카페·다음 카페·티스토리·주요 커뮤니티·SNS → **커뮤니티**, 그 밖 → **기타**
4. 출처가 없고 카카오톡 앱 안 브라우저면 → **공유**(단톡방 링크)
5. 나머지 → **직접**

출처 주소·검색어 원문은 저장하지 않는다. 분류 코드는 `packages/core/src/source.ts`.

## 캐시·canonical

꼬리표가 붙어도 같은 캐시 페이지가 나간다(2026-10-25 운영 확인: `/서울특별시/마포구`에 `utm_*`·`ref=share`를 붙여도 `x-vercel-cache: HIT`, 같은 age). 서버는 꼬리표를 읽지 않고, canonical은 경로만 쓴다. 페이지가 서버에서 검색 꼬리표(`searchParams`)를 읽기 시작하면 캐시가 쪼개지니 그때 다시 확인한다.
