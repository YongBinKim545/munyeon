## 1. P0-1 — DB의 시도 이름 실태

2026-10-23 조사 시점(마이그레이션 0007 전)의 분포다.

| 주소 첫 단어 | 병원 | 약국 | 그때 저장된 시도 |
|---|---|---|---|
| 전남광주통합특별시 | 4,923 | 90 | 없음(우리 시도 목록에 없는 이름) |
| 광주광역시 | 0 | 710 | 광주광역시 |
| 전라남도 | 0 | 785 | 전라남도 |
| 광주 / 전남(줄임말) | 0 | 3 / 4 | 없음 |
| 그 밖의 줄임말(서울·경기·인천·대구 등) | 0 | 약 85 | 없음 |
| 시군구가 없는 주소(예: `경기도 금빛로 27`) | 7 | 0 | 없음 |

- **원인:** 병원 데이터는 2026-07-01 통합 뒤 새 이름으로 바뀌었고, 약국 데이터는 대부분 옛 이름이었다. 우리 시도 목록이 새 이름과 줄임말을 몰랐다.
- **시군구 이름은 겹치지 않는다.** 통합특별시 안에서 옛 광주는 5개 구(동구·서구·남구·북구·광산구)이고, 옛 전남은 시·군뿐이다.
- **운영:** 수정 전 `/regions`에서 광주광역시와 전라남도 모두 병원이 0곳이었다.
- **조치(D55, 2026-10-23 운영 반영):** 새 이름·옛 이름·줄임말을 모두 지금 이름으로 묶었다. 운영 `/regions`의 전남광주통합특별시는 약국 1,591곳, 병원 4,904곳이다.
- **남은 것:** 시군구가 없는 주소의 병원 7곳은 시도 없이 남는다. 상세 페이지는 있고 지역 페이지에만 나오지 않는다.

## 2. P1-1 — IndexNow 하루 한도

공식 문서([indexnow.org/documentation](https://www.indexnow.org/documentation)) 기준이다.

- 한 번에 보내는 주소는 **최대 10,000개**다.
- **하루 한도는 적혀 있지 않다.**
- 응답 코드:
  - 200: 받음. 색인을 약속하는 뜻은 아니다
  - 202: 받음. 키 확인 대기 중
  - 400: 형식 오류
  - 403: 키 오류
  - 422: 주소가 다른 사이트이거나 키가 맞지 않음
  - 429: 너무 잦음(스팸 의심)
- 키는 8~128자이고 영문자·숫자·`-`만 쓴다. 사이트 루트에 `{키}.txt`로 둔다.
- 하루 1만 개라는 수치는 Bing의 옛 URL 제출 API 한도를 옮겨 적은 2차 자료들에 나온다. 공식 한도는 아니다.

**적용 방향:** P1-1 확정 내용대로 매시간 바뀐 상세와 그 지역 페이지만 보낸다. 평소 변경량은 시간당 수십~수백 개라 한 요청에 들어간다. 429가 나면 그 회차는 건너뛰고 로그에 남긴다. 공개 첫날 전체 주소는 보내지 않는다(사이트맵 제출로 대신).

## 3. P1-7 — 심평원 의료기관별 상세정보 API

**API:** 건강보험심사평가원 의료기관별상세정보서비스, 현재 판은 `MadmDtlInfoService2.8/getDtlInfo2.8`이다. 2.7은 폐기됐다(2026-10-23 호출 결과 `NO_OPENAPI_SERVICE_ERROR`).

**필드:**
- 요일별 진료 시작·종료(`trmtMonStart`~`trmtSunEnd`)
- 평일·토요일 점심시간(`lunchWeek`, `lunchSat`)
- 평일·토요일 접수시간(`rcvWeek`, `rcvSat`)
- 일요일·공휴일 휴진 안내(`noTrmtSun`, `noTrmtHoli`)
- 응급실 주간·야간 운영 여부와 전화번호
- 위치 안내

공식 활용가이드는 받지 못했다. 필드 이름은 실제 응답으로 확인했다는 공개 저장소 기록([myopiaBackend PR #110](https://github.com/jin0008/myopiaBackend/pull/110))으로 확인했다.

**값 형식:**
- 시작은 문자열 `"0830"`, 끝은 숫자 `1730`으로 섞여 온다. 네 자리로 맞춰 읽어야 한다(같은 기록).
- 점심·접수시간은 자유 문장이라 파싱해야 한다.

**호출 한도와 비용:**
- 심평원 병원정보서비스의 개발계정은 하루 10,000건이고, 운영계정은 활용사례를 등록하면 늘릴 수 있다([공공데이터포털](https://www.data.go.kr/data/15001698/openapi.do)). 상세정보 서비스도 같은 체계로 본다.
- 상세정보는 기관 하나에 1회 조회다. 병원 약 7.9만 곳을 한 바퀴 돌려면 개발계정으로 8일이 걸린다.
- 조회 키가 심평원 기관 기호(`ykiho`)라 국립중앙의료원 기관 ID(`hpid`)와 바로 이어지지 않는다. 심평원 병원 목록(`getHospBasisList`)을 받아 이름·주소·전화로 맞추는 작업이 먼저 필요하다.

**채움률:**
- 우리 공공데이터 키는 심평원 API에 활용신청이 안 돼 있다(2026-10-23 호출 결과 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`). 그래서 표본 채움률은 재지 못했다.
- 대신 지금 데이터의 자유 문장(`dutyEtc`·`dutyInf`)을 봤다. 병원 27,802곳(35%)이 '점심' 또는 '휴게'를, 5,079곳(6%)이 '접수'를 언급한다.
- 기획 문서의 "소개문 9.3%"는 `dutyInf` 한 칸만 센 수치다. `dutyEtc`까지 보면 더 많다.

**결론:** 설 이후 D28 재검토 때 정한다. 연동하려면 다음이 필요하다.
1. 사용자가 공공데이터포털에서 '의료기관별상세정보서비스'와 '병원정보서비스'를 활용신청한다. 계정 작업이라 사용자가 한다.
2. `hpid`↔`ykiho` 맞추기.
3. 운영계정 증량.

표본 채움률이 먼저 필요하면 1번만 하면 개발 세션이 100곳 표본을 잴 수 있다.

## 4. P1-9 — 달빛 진료 시간이 데이터에 따로 있는지

- **전용 칸이 없다.** 국립중앙의료원 병·의원 데이터의 칸은 요일별 진료시간(1~8)·응급실 여부·소개문·비고뿐이다. 달빛어린이병원 지정 여부도 시간도 따로 없다.
- 자유 문장에 '달빛어린이'를 적은 기관은 19곳뿐이다. 예: "달빛어린이병원운영(월~금 09:00~23:00, 토요일 09:00~18:00…)".
- 전국 지정 기관은 2025-07 말 121곳, 같은 해 10월 보도 기준 126곳이다([메디게이트뉴스 2025-10](https://medigatenews.com/news/3136261714)). 대부분은 자유 문장에도 적지 않았다.
- 이름에 '달빛'이 든 16곳은 달빛여성의원처럼 지정과 무관한 곳이 섞여 있다. 이름으로 판정할 수 없다.
- 공공데이터포털에서 전국 달빛어린이병원 목록 데이터셋은 찾지 못했다. 지정 목록은 D3대로 보건복지부·시도 발표를 모아 직접 관리해야 한다.

**결론:** P1-9 확정 내용대로 달빛 진료 시간 구분 표시는 빼고, 배지와 `/달빛어린이병원` 페이지만 낸다. 등록 진료시간에는 달빛 시간이 이미 들어 있는 경우가 많다(평일 23시까지 등).

## 5. P2-5 — 응급실 운영 여부와 응급실 전화

| 구분 | 곳 수 |
|---|---|
| `dutyEryn`=1(응급실 운영) | 521 (종합병원 374, 병원 132, 보건소 13, 의원 1, 치과병원 1) |
| 그중 `dutyTel3`(응급실 전화) 있음 | **521 (100%)** |
| 그중 `dutyTel3`가 대표번호와 같음 | 31 |
| `dutyEryn`=2인 종합병원 | 6 |

- **채움률:** `dutyEryn`은 병원 78,988곳 모두 1 또는 2로 채워져 있다(빈칸 없음).
- **응급실 전화:** `dutyTel3`은 응급실 운영 기관에만 있다(전체 522곳). 대부분 `…-7119`, `…-2119`처럼 응급실 전용 번호다.
- **시도 분포:** 경기 96, 서울 75, 전남광주 67, 경남 46, 부산 38, 경북 35, 인천·대구 25, 강원 23, 전북 21, 충남 20, 충북 19, 울산 13, 대전 11, 제주 5, 세종 2. 응급실이 하나도 없는 시도는 없다.
- **목록 파일 크기:** 521곳이면 전국 응급실 목록 파일은 수십 KB 안이다. P2-5 확정 내용대로 하루 1회 파일로 둘 수 있다.

**결론:** 구현 때 `dutyEryn`=1을 응급실 운영으로, `dutyTel3`을 [전화하기] 번호로 쓴다. 의원 1곳과 치과병원 1곳은 예외로 보이므로 표시 전에 확인한다.

## 6. 결정 3 — 공공심야약국·편의점 안전상비의약품 데이터

**공공심야약국**
- 2026-07 기준 전국 240곳이다([데일리팜](https://m.dailypharm.com/user/news/342812)).
- 2024-04 약사법으로 제도화된 뒤 지자체 보조사업으로 운영된다.
- **전국 단위 공공데이터는 찾지 못했다.** 공공데이터포털에는 전주시 7곳 같은 지자체별 파일만 있다([전주시](https://www.data.go.kr/data/15143815/fileData.do)). 지자체마다 형식·갱신이 제각각이다.
- 국립중앙의료원 약국 데이터에는 공공심야 지정 칸이 없다. 진료시간(밤 10시~새벽 1시 등)으로만 간접 추정할 수 있다.

**편의점 안전상비의약품 판매업소**
- 행정안전부 지방행정 인허가 데이터로 전국 파일이 있다([공공데이터포털 15045034](https://www.data.go.kr/data/15045034/fileData.do)).
  - 84,631행, 수시 자동 갱신, 2025-11-27 수정 기준
  - 법령 소관은 식품의약품안전처
- 영업상태(영업·폐업)와 주소가 있다.
- 좌표는 Bessel 중부원점 TM(EPSG:5174)이라 WGS84 변환이 필요하다. 좌표 칸이 모든 행에 있는지는 파일을 받아 확인해야 한다.
- **영업시간 칸이 없다.** '지금 문 연 편의점'은 알 수 없고, 24시간 편의점이라고 가정해야 한다.

**결론:** 설 이후 D28 재검토 때 정한다.
- 공공심야약국은 데이터 출처가 흩어져 있어 관리 부담이 크다. 지금처럼 진료시간 기준 '야간' 배지(P1-4)와 가이드 링크(P1-5)로 대신한다.
- 편의점 상비약은 전국 파일이 있다. 다만 시간 정보가 없고 좌표 변환이 필요해 "근처 편의점" 표시는 설 전에 하지 않는다(D28, P1-5 확정 내용과 같음).
