# 메인 목록(현재 위치 기준) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> 작성: 2026-10-19 · 근거: [DECISIONS](../DECISIONS.md) D31~D35, [기능 정의서](../specs/2026-10-18-mvp-features.md) 4.3·4.4, [구조 설계·UI/UX](../specs/2026-10-18-architecture-ux.md) 4.2·4.4·4.5. [Phase 1a 계획](2026-10-18-phase-1a.md)의 Task 1~15는 완료됐고, 이 계획은 그 위에 더한다. Task 16(배포)은 이 계획이 끝난 뒤 사용자가 요청할 때 한다.

**Goal:** 메인(`/`)을 열면 현재 위치에서 가까운 지금 영업 중인 약국(또는 병원)이 바로 보인다. 메인 전용 헤더로 지역·유형·상태를 바꾸고, 위치 검색은 모달, 상호 검색은 `/search` 페이지에서 한다.

**Architecture:**
- `packages/core`: 목록 순서 규칙(영업 중 → 곧 영업 → 전화 확인 필요 → 나머지), 격자 번호·거리 계산. 순수 함수, 테스트 먼저.
- `packages/db`: 격자 번호 생성 열 + 칸 단위 조회, 상호 검색 거리순.
- `apps/web`: `/api/grid/{유형}/{격자}`(CDN 1시간), 메인 헤더·목록·위치 검색 모달(클라이언트), `/search` 페이지. 좌표는 브라우저에만 있고 서버에는 격자 번호만 간다.

**Tech Stack:** 기존과 같다(Next.js 16 App Router, React 19, Vitest + Testing Library(jsdom), PGlite + PostGIS 테스트 DB). 새 라이브러리는 넣지 않는다.

## Global Constraints

Phase 1a 계획의 Global Constraints를 그대로 따른다. 이 계획에서 특히 중요한 것:

- '영업 중'·'곧 영업'·'전화 확인 필요' 같은 현재 상태는 서버 HTML·격자 JSON·검색 JSON에 넣지 않는다. 목록은 마운트 뒤 브라우저에서만 그린다.
- 위치 좌표를 서버·GA4·이벤트로 보내지 않는다. 서버로 가는 것은 격자 번호(약 5km)뿐이다. 유형·최근 지역도 브라우저 저장소에만 둔다.
- 브라우저 저장소 읽기·쓰기는 모두 `try/catch`로 감싸고, 실패해도 기본값으로 동작한다(사생활 보호 모드).
- 목록 순서는 거리·상태 규칙으로만 정한다. 금전이 개입하지 않는다.
- 119 전화 버튼 없음. 결과 0곳일 때 링크 없는 응급 안내 문구.

## Review Focus

1. **곧 영업의 자정 넘김:** 23:30에 00:30 여는 곳(내일 요일코드, 내일이 공휴일이면 코드 8)이 '곧 영업 · 1시간 뒤 새벽 12시 30분'으로 잡혀야 한다. → Task 1 `nextOpening crosses midnight`.
2. **공휴일 '전화 확인 필요':** 공휴일인데 코드 8이 없고, 평소 그 요일 시간으로 지금 영업 중일 때만. 평소 시간도 없으면 넣지 않는다. 코드 8이 있으면 그 시간으로만 판정한다. → Task 1 `holidayUsual only when code 8 missing`.
3. **현재 상태가 캐시에 섞임:** `/` HTML과 격자 JSON에 '영업 중'·'곧 영업'·'전화 확인 필요' 문자열이 없어야 한다. → Task 3·5 테스트, Task 7 `check-routes`.
4. **좌표 유출:** 격자 API·검색 API 요청 주소에 위도·경도가 없어야 한다. → Task 4 `requests carry grid ids only`.
5. **휴대폰 뒤로 가기:** 위치 검색 모달이 열린 상태에서 뒤로 가기를 누르면 모달만 닫히고 메인에 남는다. 모달 없이 뒤로 가기를 누르면 평소처럼 이전 페이지로 간다. → Task 5 `back closes modal only`.
6. **격자 JSON 크기:** 실측(강남역 병원 3km 194KB) 뒤 D36으로 해결: 줄인 형식 + 1km 먼저(50KB) → 3km(153KB).
7. **늦게 온 기관의 순서:** 3km 데이터가 늦게 와도 영업 중은 곧 영업·문 닫은 곳보다 앞이고, 보던 카드는 화면 위치가 그대로다. → Task 5 `late arrivals keep order and anchor`.
